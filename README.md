# Clube da Chave

Sistema minimalista para organizar campeonatos de sinuca, cadastrar jogadores,
associar participantes e montar chaveamentos.

## Recursos

- Login demonstrativo sem autenticação real
- Cadastro e gestão de jogadores
- Cadastro e gestão de campeonatos
- Associação e ordenação de participantes
- Geração automática do chaveamento
- Agenda de partidas
- Persistência no `localStorage`
- Interface responsiva

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
